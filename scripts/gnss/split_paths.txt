# git filter-repo --paths-from-file for kotekan -> gnss-broker (path-preserving, ONE pass, no --invert-paths).
# This file lists itself (the scripts/gnss regex), so it goes along as the record of how gnss-broker was made.
#
#   git clone --no-local --single-branch --branch <branch> <kotekan checkout> gnss-broker
#   cd gnss-broker && git filter-repo --paths-from-file scripts/gnss/split_paths.txt
#
# A fresh clone of the one branch, since filter-repo rewrites every ref it has. Then, before the first push:
#   git tag -l | xargs -r git tag -d     # kotekan's tags: the 3 that point into the history kept
#   git branch -m main
#   cp .git/filter-repo/commit-map docs/kotekan_commit_map.txt    # old kotekan SHA -> new SHA
#   git add docs/kotekan_commit_map.txt && git commit    # the new repo's first commit, so the
#                                                        # kotekan SHAs the docs cite translate
#
# Plain lines are literal path prefixes (dir/ or exact file); 'regex:' lines use re.search (hence the ^ anchors);
# 'glob:' lines use fnmatch ('*' also matches '/'). filter-repo applies the lines IN ORDER per path: a filter
# line only tests the name as renamed by the rename lines ABOVE it, so the one rename line is LAST.
# Stays in kotekan (excluded inside the two regex: lines by negative lookahead): every C++ harness, the
# tool symlinks/binary, scripts/gnss/.gitignore, build_tool.sh (both paths), and the 12 Python files that only
# verify kotekan's C++: python/scripts/gnss/{b1i_b3i,b2b,e5b,e6,glonass_ca,l1cd,l2oc,l3oc}_code_check.py,
# python/scripts/gnss/test_code_check_cpp.py, scripts/gnss/{trim_sign_gate,test_trim_sign_gate,test_e2e_exact_seed}.py.
# python/scripts/gnss/kotekan_src.py moves AND stays (kotekan keeps its copy).

# its files from its own checkout looks for them in kotekan: the broker config/gnss_chains_chord.yaml, the site
